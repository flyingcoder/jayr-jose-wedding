# attire-guide Specification

## Purpose

Communicates the wedding's motif colors and the dress code expected of each guest type so attendees can prepare appropriate attire in advance.

## Requirements

### Requirement: Motif color display
The system SHALL display the two wedding motif colors (light blue and light green) as visible swatches.

#### Scenario: Motif swatches visible
- **WHEN** a visitor scrolls to the Attire section
- **THEN** both the light blue and light green motif swatches are displayed

### Requirement: Dress code by guest type
The system SHALL display the expected attire for each guest type: principal sponsors (ninong: traditional barong and black slacks; ninang: long dress), gentlemen (polo or long sleeves), and ladies (long dress, maxi, or mini dress).

#### Scenario: Dress code visible per guest type
- **WHEN** a visitor scrolls to the Attire section
- **THEN** the attire expectations for principal sponsors, gentlemen, and ladies are each displayed distinctly
